# Guía de Estudio para Desarrolladores Java SE 21

Esta es una guía de estudio para el examen Java SE 21 Developer (1Z0-830).

## Sobre este material
El contenido de esta guía ha sido adaptado para su uso en la cátedra de **Programación 2**. Aquí encontrarás la base teórica necesaria para comprender el funcionamiento interno de Java y las mejores prácticas de desarrollo.

## Capítulos
Puedes navegar por los capítulos directamente desde la raíz del repositorio o utilizando los enlaces en este directorio.
