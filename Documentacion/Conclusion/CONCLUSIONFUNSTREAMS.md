# Conclusion Funcional y Streams

La guia permitio practicar los conceptos centrales de programacion funcional en Java desde una estructura mas clara y mantenible. La modularizacion del proyecto ayudo a separar la responsabilidad de ejecutar, mostrar, modelar datos y resolver cada bloque de ejercicios, lo que vuelve el codigo mucho mas facil de leer, explicar y extender.

Desde el punto de vista conceptual, los ejercicios recorren el uso de expresiones lambda, interfaces funcionales, variantes primitivas, pipelines de `Stream`, transformaciones, filtros, reducciones y recoleccion en estructuras finales. Tambien se trabajo con `Optional`, que aporta una forma mas segura y expresiva de manejar resultados que pueden o no existir.

Como conclusion final, se puede observar que Java funcional permite escribir soluciones mas declarativas, reutilizables y ordenadas. En esta version, ademas, la organizacion en clases por seccion deja una base mucho mejor para seguir creciendo el proyecto sin concentrar toda la logica en un unico archivo.
